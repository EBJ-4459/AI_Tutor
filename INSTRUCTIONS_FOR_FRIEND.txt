======================================================================
   AI TUTOR PLATFORM - SETUP INSTRUCTIONS
======================================================================

Hello! Follow these 3 simple steps to run the AI Tutor project:

----------------------------------------------------------------------
STEP 1: MAKE SURE YOU HAVE PYTHON AND NODE.JS INSTALLED
----------------------------------------------------------------------
1. Python (version 3.10 or 3.11):
   Download: https://www.python.org/downloads/
   * CRITICAL: During Python installation, check the box:
     "Add python.exe to PATH"

2. Node.js (LTS version):
   Download: https://nodejs.org/

----------------------------------------------------------------------
STEP 2: RUN THE ONE-CLICK INSTALLER
----------------------------------------------------------------------
Simply double-click the file named:
    install.bat

This automatically installs all required Python AI packages (PyMuPDF, 
ChromaDB, MediaPipe, OpenCV, Edge-TTS, FastAPI) and Vite React packages.

----------------------------------------------------------------------
STEP 3: ADD YOUR FREE GEMINI API KEY
----------------------------------------------------------------------
1. Open the file:
   avatar-chatbot/backend/.env
   (You can open it with Notepad).

2. Paste your free Gemini API key:
   GEMINI_API_KEY=your_key_here

   * If you don't have one, get a free key in 30 seconds at:
     https://aistudio.google.com/

----------------------------------------------------------------------
STEP 4: START THE APPLICATION!
----------------------------------------------------------------------
Double-click:
    run_local.bat

Your browser will automatically open:
   - Main AI Tutor UI:        http://localhost:5173
     * Tutor Aria (3D Talking Avatar + Interactive Chat + Awareness Checker)
     * Knowledge Base (Document Upload & Subject Manager)

Enjoy learning with your 3D AI Tutor!
